# p108 · 内容修复方案（Google Discover 更新后）

> 原文：https://peixun.seogo123.co/p108.html ｜ 归档：`text/p108.md`

## 1. 核心论点（≤3 句）

面向**已上线、已有收录或排名**的存量内容做修复，目标不是增加文章数量而是提升结构质量、主题表达能力与阅读体验（"适用于"+"一、内容修复目标"）。
把内容从"内容薄 / 主题泛 / 标题党 / 结构混乱 / 深度不足"修成可被 Discover 推荐、可被语义理解的标准结构文章（"一"）。
核心结论：修复不是把文章写长，而是让文章从"可发布内容"升级为有结构、易理解、可持续获得推荐的内容（"十、核心结论"）。

## 3. 背景理论（不能直接变成规则）

- **修复的系统识别目标**：Google Discover 推荐、搜索引擎语义理解、用户阅读体验、主题专业性识别（"一"）——是目标框架。
- **低质量状态的五种画像**（内容薄/主题泛/标题党/结构混乱/深度不足）——诊断分类，需要人工判断。
- **优先级依据 Search Console 的曝光/点击/停留数据**——依赖 GSC 数据接入，属于运营前提而非写作规则。
