# p078 · 吃瓜新闻类文章发布通用范本（E-E-A-T）

> 原文：https://peixun.seogo123.co/p078.html ｜ 归档：`text/p078.md`

## 1. 核心论点（≤3 句）

吃瓜类内容要靠 E-E-A-T 四要素（Experience / Expertise / Authoritativeness / Trustworthiness）把"爆料"升级为"专业解读"（开篇 + "标题设计"）。
原文明确指出动机是安全：吃瓜类内容"最怕造谣误伤"，作者/审校的专业身份能显著提升安全性和可信度（"核心信息区"注）。
落地方式是一套固定模块范本：标题 → 核心信息区 → 事件复盘（时间线表）→ 深度解析 → 经验洞察 → 权威建议 → 官方回应 → 理性结语。

## 3. 背景理论（不能直接变成规则）

- **E-E-A-T 四要素与模块的映射关系**：Trustworthiness→核心信息区与官方回应；Expertise→深度解析；Experience→经验洞察；Authoritativeness→专业建议。这是设计意图说明，本身不是操作项。
- **适用范围声明**：恋情瓜、塌房事件、争吵冲突、突发舆情、热搜解读（开篇）。
- **蓝战非案例的具体内容**（跨国犯罪趋势四特征、三条安全提醒、使领馆建议等）属于**该案例的实体内容**而非通用规则，不能直接抄进写作规范。
