# p045 · 文章内容发布以及架构规范

> 原文：https://peixun.seogo123.co/p045.html ｜ 归档：`text/p045.md`

## 1. 核心论点（≤3 句）

内容发布规范决定内容"能不能被收录、能不能排名、能不能带来转化"，是 SEO 落地的核心部分（原文"总体目标"前言）。
它要求同时满足搜索引擎算法与用户阅读体验，并通过标准化模板保证团队一致性（"一、总体目标"）。
结论句：高质量内容不等于文字好看，而是"结构正确、标签标准、语义清晰、可被机器理解"（"九、一句话总结"）。

## 3. 背景理论（不能直接变成规则）

- **四个目标维度**：收录概率（Indexability）、结构与内链（Structure）、停留与转化（Engagement）、团队一致性（"一、总体目标"）——是评价框架，不是可执行条目。
- **发布前准备五项**：关键词研究、搜索意图分析（学习/购买/比较/下载）、内容定位（引流/转化/品牌曝光）、竞争对手分析、内容分层（pillar + cluster）（"二、发布前准备"）——属于选题上游流程，需要人工/工具介入，无法写成成文规范。
- **收尾金句**："规范化内容发布 = 搜索引擎易抓取 + 用户易阅读 + 权重易积累"（"九"）。

## 4. 存疑项

| 编号 | 存疑内容 | 冲突对象 |
|---|---|---|
| Q045-a | **关键词密度 2%~3%**（R045-29） | 与 p108"核心关键词自然出现 2~3 次"、p111"主词出现 5–8 次"三方数值互不一致，且 2%~3% 对 700~1200 字文章意味着主词出现 14~36 次，量级远超另两篇 |
| Q045-b | **每段不超过 150 字**（R045-30） | 与 p112"每 3 行换段"不是同一度量口径，需换算或择一 |
| Q045-c | **搜索意图分类为"学习/购买/比较/下载"** | 该分类面向教程/电商站，与吃瓜资讯站的"追热点"意图不对应（本站场景适配性存疑） |
| Q045-d | **Keywords meta 标签（R045-17）** | 原文标注"可选"，未说明现代搜索引擎是否仍采信 |
| Q045-e | **外链一律 nofollow（R045-07）** | 与 p078"引用官方通报/媒体报道以建立 Trustworthiness"的取向存在张力：p078 鼓励引用权威来源，p045 要求引用一律 nofollow |
